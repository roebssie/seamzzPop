# seamzzPop roadmap

This is a directional roadmap, not a promise that every item will ship in the listed order.

## Near term

- Agree on the first user persona and simplest supported garment.
- Document source-permission and attribution requirements.
- Create a small annotated set of consented garment references.
- Sketch the measurement, garment-attribute, and pattern-source data models.

## Next

- Prototype rights-aware pattern discovery with transparent similarity reasons.
- Test measurement capture with sewists and sewing educators.
- Draft one constrained garment family parametrically.
- Validate PDF tiling and print calibration with physical test pieces.

## Later

- Evaluate image-assisted attribute recognition.
- Add user correction and confidence workflows.
- Expand garment categories only after fit and export tests pass.
- Explore creator partnerships and a pattern-source contribution workflow.

## Success signals

- Makers can understand why a pattern was suggested.
- Users can identify the rights and source of every downloadable asset.
- A test garment can be printed, assembled, and adjusted with predictable results.
- The system communicates uncertainty honestly and supports manual expertise.
